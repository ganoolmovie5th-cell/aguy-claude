# aguy.web.id

Website portofolio pribadi. Static site, tanpa build step.

## Stack

HTML, CSS, dan JavaScript vanilla. Tidak ada dependency.

## Struktur

- `index.html` — halaman utama
- `style.css` — gaya
- `script.js` — tahun footer otomatis
- `og.svg` — gambar preview sosial

## Jalankan lokal

Buka `index.html` di browser, atau:

```bash
npx serve .
```

## Deploy

Di-deploy ke Vercel dari branch `main`. Framework preset: **Other** (static).
Root directory: root repo. Tidak ada build command.

Domain: [aguy.web.id](https://aguy.web.id)

## Edit konten

Semua teks ada di `index.html`. Ganti nama proyek, bio, dan link kontak di sana.
